# Security Policy

## Supported Versions

The project is currently at version 0.1.0 (see `package.json`). Only the current development line receives security updates; there are no released 4.x or 5.x lines.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

Version 0.1.0 is the current supported version. Older versions are not supported.

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do not open a public issue for a suspected vulnerability.

- **Preferred channel:** GitHub's private vulnerability reporting — open a report at
  https://github.com/keanehatescoding/land-title-monitor/security/advisories/new
- **Alternative:** If private reporting is unavailable, email the maintainer privately at
  `159132270+keanehatescoding@users.noreply.github.com` with a description of the issue.
  Do not post vulnerability details publicly.

What to expect:

- Acknowledgement of your report within 72 hours.
- A status update at least every 7 days while the issue is being investigated.
- If the vulnerability is accepted, a fix will be developed and released, and you will be
  credited in the release notes unless you request otherwise.
- If the vulnerability is declined (for example, it is out of scope or cannot be reproduced),
  you will receive an explanation. Please allow time for triage before following up.

Please include, where possible: a description of the issue, steps to reproduce, the affected
version/commit, and any suggested mitigation.
